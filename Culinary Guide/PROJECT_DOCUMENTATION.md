## 一、项目目的

### 1.1 项目概述

**Culinary Guide（美食指南）** 是一款基于 .NET MAUI 开发的跨平台移动应用，旨在帮助用户发现、探索和管理周边餐厅信息。

### 1.2 解决的问题

| 问题 | 描述 |
|------|------|
| **信息分散** | 用户需要在多个平台（大众点评、美团、小红书）之间切换，信息碎片化 |
| **决策困难** | 面对大量餐厅选择，用户难以快速做出决策 |
| **收藏无序** | 用户收藏的餐厅分散在各平台，缺乏统一管理 |
| **位置感知弱** | 传统应用无法直观展示餐厅与用户的相对位置 |

### 1.3 目标用户

- 寻找周边美食的城市居民
- 探索新餐厅的美食爱好者
- 需要管理收藏餐厅的用户

### 1.4 项目范围

```
┌─────────────────────────────────────────────────────────┐
│                    Culinary Guide                        │
├─────────────────────────────────────────────────────────┤
│  ✅ 餐厅浏览与搜索                                        │
│  ✅ 收藏管理                                              │
│  ✅ 餐厅详情与评论                                        │
│  ✅ 用户资料编辑                                          │
│  ✅ 多语言支持                                            │
│  ⚠️  地图探索（模拟实现）                                  │
│  ❌ 云同步（未实现）                                       │
│  ❌ 推送通知（未实现）                                     │
└─────────────────────────────────────────────────────────┘
```

#### 3.3.1 餐厅列表浏览（F01）

**解决方案**：
- 使用 `CollectionView` 实现高性能虚拟化列表
- 从嵌入式 JSON 加载餐厅数据
- 支持增量加载

**代码示例**：
```xml
<CollectionView ItemsSource="{Binding FilteredRestaurants}"
                SelectionMode="Single"
                SelectionChanged="OnRestaurantSelected">
    <CollectionView.ItemTemplate>
        <DataTemplate>
            <Border StrokeShape="RoundRectangle 12">
                <!-- 餐厅卡片内容 -->
            </Border>
        </DataTemplate>
    </CollectionView.ItemTemplate>
</CollectionView>
```

**技术选择理由**：
- `CollectionView` 比 `ListView` 性能更优，支持虚拟化
- 嵌入式 JSON 避免网络依赖，提升加载速度

#### 3.3.4 GPS 定位与距离计算（F11/F12）

**解决方案**：

**定位服务接口**：
```csharp
public interface ILocationService
{
    Task<Location> GetUserLocationAsync();
    double CalculateDistance(double lat1, double lon1, double lat2, double lon2);
}
```

**距离计算（Haversine 公式）**：
```csharp
public double CalculateDistance(double lat1, double lon1, double lat2, double lon2)
{
    var d1 = lat1 * (Math.PI / 180.0);
    var num1 = lon1 * (Math.PI / 180.0);
    var d2 = lat2 * (Math.PI / 180.0);
    var num2 = lon2 * (Math.PI / 180.0) - num1;
    var d3 = Math.Pow(Math.Sin((d2 - d1) / 2.0), 2.0) + 
             Math.Cos(d1) * Math.Cos(d2) * 
             Math.Pow(Math.Sin(num2 / 2.0), 2.0);
    
    return 6376500.0 * (2.0 * Math.Atan2(
        Math.Sqrt(d3), Math.Sqrt(1.0 - d3))) / 1000; // 返回公里
}
```

**权限处理**：
```csharp
var status = await Permissions.CheckStatusAsync<Permissions.LocationWhenInUse>();
if (status != PermissionStatus.Granted)
{
    status = await Permissions.RequestAsync<Permissions.LocationWhenInUse>();
}
```

public async Task<string?> PickAvatarAsync()
{
    var photo = await MediaPicker.PickPhotoAsync(new MediaPickerOptions
    {
        Title = "选择头像"
    });
    
    if (photo == null) return null;
    
    // 保存到应用目录
    var avatarDir = Path.Combine(
        FileSystem.Current.AppDataDirectory, "avatars");
    Directory.CreateDirectory(avatarDir);
    
    var filePath = Path.Combine(avatarDir, 
        $"avatar_{DateTime.Now:yyyyMMddHHmmss}.jpg");
    
    using var sourceStream = await photo.OpenReadAsync();
    using var destStream = File.Create(filePath);
    await sourceStream.CopyToAsync(destStream);
    
    return filePath;
}

### 3.5 方案评估

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| 嵌入式 JSON 数据 | 加载快、无网络依赖 | 数据不实时 | ✅ 适合 MVP |
| SQLite 本地存储 | 轻量、跨平台 | 无云同步 | ✅ 适合单设备 |
| GraphicsView 模拟地图 | 无需第三方依赖 | 功能有限 | ⚠️ 过渡方案 |
| 事件驱动更新 | 解耦、响应式 | 需手动管理订阅 | ✅ 适合小型应用 |

## 五、与原计划的偏离

### 5.1 偏离记录

| 原计划功能 | 实际实现 | 偏离原因 | 记录 |
|------------|----------|----------|------|
| **地图探索功能** | 模拟地图 + GPS定位 + 距离计算 | 需要调用第三方地图API（如高德、百度、Google Maps），无可用API Key；改为实现GPS定位服务和餐厅距离计算，确保定位功能仍有实际价值 | ✅ 已记录 |
| 网络数据源 | 嵌入式 JSON | MVP 阶段简化实现，避免后端依赖 | 合理 |
| 云同步收藏 | 本地 SQLite | 需要用户系统支持，暂不实现 | 合理 |
| 深度筛选（价格区间） | 仅搜索和排序 | UI 复杂度高，延后实现 | 已记录 |
| 社交分享 | 未实现 | 需要第三方 SDK，延后实现 | 已记录 |
| 推送通知 | 占位页面 | 需要后端支持，延后实现 | 已记录 |

### 5.2 地图功能偏离详解

**原计划**：
- 集成第三方地图 SDK（高德/百度/Google Maps）
- 在真实地图上标注餐厅位置
- 支持路线导航功能
- 实时显示交通状况

**实际实现**：
```
MapPage.xaml
├── GraphicsView              # 自定义绘制的模拟地图
│   └── RestaurantMapDrawable  # IDrawable 实现
│       ├── DrawMapBackground()   # 绘制背景网格
│       ├── DrawUserLocation()    # 绘制用户位置（圆形标记）
│       └── DrawRestaurants()     # 绘制餐厅标记点
│
├── ILocationService          # GPS 定位服务
│   └── RealLocationService.GetUserLocationAsync()
│
├── CalculateDistance()       # Haversine 公式计算距离
│
└── 权限处理                   # LocationWhenInUse 权限请求
```

**偏离原因分析**：

| 原因 | 详细说明 |
|------|----------|
| 无第三方 API Key | 高德/百度/Google Maps 需要申请开发者Key，涉及企业认证、审核流程 |
| 跨平台差异 | Android、iOS、Windows 地图 SDK 接入方式各异，开发成本高 |
| 费用问题 | 商业使用可能产生费用，个人项目预算有限 |
| 时间约束 | MVP 阶段优先核心功能，地图作为增强功能延后 |

**替代方案的价值**：

| 功能 | 价值 |
|------|------|
| GPS 定位 | 已验证可用，为后续接入真实地图奠定基础 |
| 距离计算 | 支持首页"按距离排序"核心功能 |
| 模拟地图 | 展示UI交互逻辑，便于后续替换 |
| 权限处理 | 已完成定位权限请求流程 |

**后续改进计划**：
1. 申请高德/百度地图 API Key
2. 集成 MAUI Maps 控件
3. 实现真实地图渲染
4. 添加路线导航功能

### 5.3 新增功能（未在原计划中）

| 新增功能 | 添加原因 | 价值 |
|----------|----------|------|
| 用户资料编辑 | 提升个性化体验 | 增强用户粘性，数据持久化 |
| 评论点赞统计 | 动态计算平均评分 | 数据更准确，实时反馈 |
| GPS 定位服务 | 支持按距离排序 | 核心功能依赖，提升实用性 |
| 浏览历史 | 记录用户行为 | 方便回溯，提升体验 |

### 5.4 技术调整

| 原计划 | 实际采用 | 调整原因 |
|--------|----------|----------|
| ListView | CollectionView | 性能更优，虚拟化支持更好 |
| 同步数据库操作 | 异步操作 | 避免阻塞 UI 线程 |
| 硬编码字符串 | 资源文件 + Localize | 支持国际化 |
| 第三方地图 SDK | GraphicsView 模拟 | 无可用 API Key |
